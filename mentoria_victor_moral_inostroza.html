Leitura do perfil

O que este CV já diz sobre você

Você tem exatamente o perfil que organismos internacionais de dados geoespaciais procuram — e ainda não sabe disso.

A maioria dos analistas de dados que quer trabalhar fora do Brasil não tem o que você tem: geoprocessamento real aplicado a problemas de território. Você usou Kernel Density Estimation e Diagramas de Voronoi para mapear padrões de crime em Sorocaba. Você coletou dados de solos via API do MapBiomas e SoilGrids. Você tem QGIS, GeoDa, Databricks, Azure, Power BI e Python em projetos reais, não em cursos. Isso é exatamente o stack que a FAO, o PNUMA, o CGIAR e o BID contratam em consultores e analistas.

O bloqueio que você identificou — não saber se vale continuar em dados para o mercado internacional — tem uma resposta clara: vale, e o caminho não é o mercado genérico de dados corporativos. É o nicho de dados geoespaciais com aplicação em desenvolvimento territorial, segurança alimentar, meio ambiente e planejamento urbano. Esse nicho tem demanda global, paga bem e tem poucos profissionais com o seu nível de formação técnica e acadêmica.

E existe um ativo que você está subestimando completamente: a cidadania chilena. Ela não é um detalhe. É a porta de entrada mais direta e imediata para o mercado de trabalho internacional — sem visto, sem processo consular, sem fila. O Chile tem um ecossistema de organismos internacionais, consultorias de impacto e startups de tecnologia que contratam analistas com inglês e perfil técnico sólido.

Ativo #1 · Cidadania chilena
Direito de trabalho imediato no Chile sem visto. Facilita processos em países do Mercosul e da OCDE. Para organismos internacionais sediados em Santiago (CEPAL, FAO Chile, OPS), é o equivalente a já estar dentro do sistema. É o ativo mais imediato e mais subestimado do seu perfil.
Ativo #2 · Stack geoespacial rara
QGIS, GeoDa, Python aplicado a GIS, Machine Learning em imagens de satélite, APIs do MapBiomas e SoilGrids, Databricks, Azure. Para o mercado internacional de dados ambientais e territoriais, essa combinação é escassa. A FAO e o CGIAR contratam consultores com exatamente esse perfil.
Ativo #3 · Dissertação aplicada
Seu mestrado mapeou furtos e roubos no entorno de estabelecimentos comerciais em Sorocaba com metodologia quantitativa rigorosa. Para o mercado internacional, isso é um estudo de caso completo em análise territorial — segurança pública, planejamento urbano e desenvolvimento territorial são temas centrais do BID, OPS e UNODC.
Ativo #4 · Trilinguismo operacional
Português nativo, espanhol fluente, inglês fluente. Para organismos com foco na América Latina — CEPAL, FAO, OPS, BID — essa combinação é diferencial direto. Reuniões em três idiomas já são parte do seu histórico profissional na QUEST/INDECX. Isso não é teoria: é prática comprovada.
Ativo #5 · Rede universitária latinoamericana
O intercâmbio na Universidad del Sur via Asociación de Universidades Grupo Montevideo é reconhecido por organismos e universidades da região. Isso abre portas para redes acadêmicas internacionais — ResearchGate, repositórios de artigos e eventos geográficos da AGB e do CLACSO — que funcionam como porta de entrada para consultorias e organismos.
Ativo #6 · Projeto de solos via API
O projeto de mapeamento com potencial de plantio por tipo de solo via MapBiomas e SoilGrids coletados por API é um projeto de agtech e segurança alimentar. Para a FAO e o CGIAR, que trabalham com análise de solo, cobertura vegetal e uso da terra em escala global, esse projeto fala diretamente ao seu core.
Análise do CV

O que precisa ser ajustado

O CV atual está estruturado para o mercado brasileiro de dados corporativos — não para o mercado internacional de dados geoespaciais nem para organismos multilaterais. Não é uma questão de conteúdo, é de reposicionamento completo.

Prioridade Alta
Não há headline nem professional summary — o leitor internacional não sabe quem você é
O CV abre com "Objetivo: Analista de Dados", que não posiciona nada para um recrutador internacional. O headline precisa nomear o nicho e o diferencial: "Geospatial Data Analyst | GIS · Remote Sensing · Spatial Statistics | Spanish · English · Portuguese | Open to relocation". O summary de três linhas logo abaixo deve conectar dados geoespaciais, desenvolvimento territorial e disponibilidade internacional. Em 6 segundos, o recrutador precisa saber exatamente onde você se encaixa.
Prioridade Alta
A seção de ferramentas é extensa mas sem contexto de aplicação
Listar "QGIS — Intermediário, GeoDa — Intermediário, Python — Básico" não comunica nada para um recrutador da FAO ou do Banco Mundial. O que importa é o contexto de uso: geoprocessamento ambiental, análise territorial, segurança alimentar, planejamento urbano. As ferramentas precisam aparecer integradas nos bullets de projetos e experiência, não como lista isolada com nível autodeclarado.
Prioridade Alta
Os projetos geoespaciais existem mas estão invisíveis
O mapeamento de crimes com KDE e Voronoi, o projeto de solos via API e o TCC de unidades geoambientais são três projetos sólidos que não existem como projetos no CV. Aparecem como linhas soltas na síntese. Para o mercado internacional, esses projetos são o portfólio — precisam de uma seção própria com: contexto do problema, dados utilizados, metodologia, ferramentas e resultado. Esse é o currículo real do Víctor.
Prioridade Média
A experiência acadêmica está subvalorizada em relação ao que o mercado internacional lê
O mestrado, o TCC publicado e o intercâmbio via Grupo Montevideo têm peso diferente em currículos internacionais do que no mercado brasileiro. A dissertação precisa aparecer com o título completo, o abstract em inglês e a metodologia destacada. O intercâmbio precisa mencionar a rede universitária e o idioma desenvolvido. Para organismos como CEPAL e FAO, formação acadêmica com rigor metodológico é critério de triagem.
Prioridade Média
Não há presença em redes acadêmicas e profissionais internacionais
ResearchGate, LinkedIn com perfil em inglês, comunidade ESRI, HOT (Humanitarian OpenStreetMap Team) e grupos de GIS no GitHub são os lugares onde recrutadores de organismos internacionais buscam profissionais de geoprocessamento. Você não existe nessas redes ainda. Criar um perfil ativo no ResearchGate com a dissertação e o TCC, e um repositório GitHub com os projetos geoespaciais documentados em inglês, é o que transforma o CV em presença verificável.
Ponto de Atenção
A cidadania chilena não está estrategicamente posicionada no CV
Atualmente aparece em "Vivência Internacional" como um dado quase decorativo. Para candidaturas no Chile e em organismos com sede em Santiago, precisa aparecer de forma direta e destacada: "Chilean citizen — immediate right to work in Chile, no visa required." Para organismos internacionais que valorizam diversidade de nacionalidades (como o sistema ONU), a dupla cidadania Brasil-Chile é um diferencial real que precisa estar no topo do documento.
Ponto de Atenção
Os bullets de experiência descrevem tarefas — não impacto
"Realização de Desk Research para aplicação de Machine Learning em Geoprocessamento" descreve o que você fez. O que o recrutador internacional quer saber é: qual era o problema, qual foi a contribuição específica e qual foi o resultado. Cada bullet precisa do formato: verbo de ação + contexto técnico + impacto mensurável ou entregável concreto. A carta de intenção — que ainda precisa ser construída — vai precisar desses dados para existir.
