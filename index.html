Como este site chegou até você
Publicado via GitHub Pages — passo a passo para o mentor
  1. 1
    Acesse github.com/new e crie um repositório com o nome mentoria-victor. Deixe-o público (necessário para GitHub Pages gratuito) e clique em Create repository.
  2. 2
    Na página do repositório vazio, clique em uploading an existing file. Arraste os três arquivos HTML de uma vez: index.html, mentoria_victor_moral_inostroza.html e mentoria_victor_complemento_encontros_3_4.html. Clique em Commit changes.
  3. 3
    Vá em Settings → Pages (menu lateral). Em Branch, selecione main e clique em Save. O GitHub leva cerca de 60 segundos para publicar.
  4. 4
    A URL do site será https://SEU-USUARIO.github.io/mentoria-victor — substitua SEU-USUARIO pelo seu nome de usuário do GitHub. Envie esse link para o Víctor.
